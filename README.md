# GREEN GARDEN LOBOS - Web Profesional

Web premium para empresa de malla romboidal galvanizada y servicios de instalación en obras de gran escala.

## 📋 Características

✅ **Diseño Responsivo** - Mobile-first, optimizado para todos los dispositivos
✅ **SEO Optimizado** - Meta tags, estructura semántica, velocidad optimizada
✅ **CTA Estratégicos** - Botón WhatsApp flotante con número de empresa
✅ **Catálogo Dinámico** - Todos los productos y servicios en una página
✅ **Sección de Proyectos** - Casos de éxito y referencias
✅ **Testimonios** - Confianza social y credibilidad
✅ **Contact Integration** - WhatsApp + Email directo

## 🎯 Estrategia de Posicionamiento

### Diferenciales:
1. **Especialización en obras 1km+** - Enfoque en grandes proyectos
2. **Solución integral** - Productos + Instalación + Consultoría
3. **Certificación ISO** - Garantía y profesionalismo
4. **Portfolio visible** - Casos reales con metraje instalado

### Target:
- Empresas constructoras (obras civiles)
- Desarrollistas inmobiliarios
- Propietarios rurales/agrícolas
- Municipalidades y gobiernos locales
